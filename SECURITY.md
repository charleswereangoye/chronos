# 🔒 Security Policy

## Supported Versions
Only the latest release on the `main` branch is actively supported with security updates.

## 🚨 Reporting a Vulnerability
If you discover a security vulnerability or sensitive token leakage issue within Chronos:
1. **Do NOT open a public GitHub Issue.**
2. Send an email directly to **charleswereangoye@gmail.com** with the subject line `[SECURITY VULNERABILITY] Chronos`.
3. Include detailed steps to reproduce the issue.

We will acknowledge receipt within 48 hours and work with you to patch the vulnerability responsibly before public disclosure.
